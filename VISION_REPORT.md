# Vision Report: Project Omni
**Vision Statement**: To democratize software engineering by providing an AI-native workspace that transforms natural language intent into production-ready software systems.

## 1. The Goal
Omni is not just a code generator; it is an **Integrated Intelligence Environment (IIE)**. It should bridge the gap between "prototype" and "production" by managing the entire lifecycle of an application.

## 2. Core Features (The "Omni 9")
1. **Omni-Chat**: Context-aware AI assistant that understands the entire codebase.
2. **Infinite Workspace**: A file explorer that handles multi-module projects seamlessly.
3. **Ghost-Editor**: A real-time code editor with AI-powered diffing and suggestions.
4. **Live-Mirror**: Instant hot-reloading preview for all supported frameworks.
5. **Hyper-Terminal**: A virtualized terminal for build logs and command execution.
6. **Forge-Build**: Persistent build states with automatic failure recovery.
7. **Omni-Deploy**: One-click deployment to cloud infrastructure.
8. **Chronos-History**: Git-integrated versioning with time-travel capabilities.
9. **Nexus-Settings**: Centralized configuration for keys, models, and environments.

## 3. Architecture Strategy
- **Frontend**: React 19 + Tailwind + Motion for a fluid, high-performance UI.
- **Backend**: Express + Vite (Full-stack) for secure AI proxying and workspace interaction.
- **AI**: Gemini 2.0 Flash/Pro for orchestration and code generation.
- **Persistence**: File-system based workspace with optional Cloud persistence (Firebase).
